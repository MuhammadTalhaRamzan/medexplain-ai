# MedExplain AI

AI assistant that explains medical lab reports (CBC, Lipid Profile, LFT,
KFT, Blood Sugar, Thyroid, etc.) in plain language. OCR runs locally
with EasyOCR; report explanations are generated by Gemma 4 via the
OpenRouter API. See `docs/DEVELOPMENT_PLAN.md` for the full task
breakdown and build order.

**Not a diagnostic tool.** Educational explanations only — always
consult a qualified healthcare professional.

> **Privacy note:** OCR (text extraction) happens on your machine, but
> the extracted report text is sent to OpenRouter's cloud API to
> generate the explanation. This is a change from the original PRD's
> fully offline design — see the note at the top of
> `docs/DEVELOPMENT_PLAN.md`.

## Current status

Phase A (Backend Foundation) is implemented: Express server, health
check, and AI provider status check. Upload, extraction, and AI
analysis land in later phases per the development plan.

## Prerequisites

- Node.js 18+
- Python 3.9+ with EasyOCR (`pip install -r backend/services/ocr/requirements.txt`) — needed starting Phase C
- An [OpenRouter](https://openrouter.ai/keys) API key — needed starting Phase D

## Backend setup

```bash
cd backend
cp .env.example .env
# then edit .env and set OPENROUTER_API_KEY
npm install
npm run dev
```

Verify it's up:

```bash
curl http://localhost:5000/health
curl http://localhost:5000/ai/status
```
